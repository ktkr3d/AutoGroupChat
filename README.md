# [AutoGroupChat](https://github.com/ktkr3d/AutoGroupChat)

## Introduction

Automatically switches chat to Group when joining a party or raid.

## Install

Install AutoGroupChat using the [WowUp](https://wowup.io/guide/get-addons/overview) app.
`Get Addons` > `Install from URL`

   ```text
   https://github.com/ktkr3d/AutoGroupChat
   ```

## Configuration

- Toggle
   ```text
   /agc
   ```

- On
   ```text
   /agc on
   ```

- Off
   ```text
   /agc off
   ```

- Show status
   ```text
   /agc status
   ```
